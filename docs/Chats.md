## Understand the Chats layout

![Figure 12. The Chats page](/img/Assets/Figure%2012%20-%20The%20Chats%20page.png)
***Figure 12.** The Chats page*

Chats has up to four panels, from left to right:

1. **Inboxes** — every WhatsApp number and Instagram account you can access, each with its unread count. The panel opens when you enter Chats and collapses after you pick an inbox.
2. **Conversations** — the conversation list for the selected inbox, newest activity first.
3. **Chat window** — the message timeline and the composer.
4. **Contact details** — the profile of the person you're chatting with. Optional.

**To resize the conversation list:** Drag the divider between the conversation list and the chat window.

**To show or hide the contact details panel:** In the chat header, select the panel icon.

**Note:** Zprox.Chat never puts phone numbers in the browser address bar. Deep links open the chat and then clean the URL.

## To open a conversation

1. Select **Chats** in the sidebar.
2. In the **Inboxes** panel, select the WhatsApp number or Instagram account you want to work in. The panel collapses and the conversation list appears.
3. Optionally narrow the list:
   - In the **Search by phone** box, type part of a number.
   - Under **Filter**, select **Filter by group** to show only contacts in a group.
   - For Instagram, use the sort control to order conversations by how soon their reply window closes.
4. Select a conversation. The chat opens and the conversation is marked as read.

**Note:** Zprox.Chat remembers the last inbox you used and reopens it next time, provided you still have access to it.

## To start a new chat

Use this when you want to message a number that isn't in the conversation list yet.

1. At the top of the conversation list, select the new-chat icon. The **New chat** dialog appears.

   ![Figure 13. New chat](/img/Assets/Figure%2013%20-%20New%20chat.png)
   ***Figure 13.** New chat*

2. In the **Phone number** box, type the number with its country code, for example `919876543210`.
3. In the **Contact name** box, type a name. This is optional.
4. Optionally select a category and groups, and a stage.
5. In the **Message** box, type your first message.
6. Select **Send**. Zprox.Chat creates the contact and opens the conversation.

**Important:** If the person has never messaged you, WhatsApp only accepts an approved template. Use **Send a template** instead of free text. See [To send a template](#to-send-a-template).

## To send a message

1. Open the conversation.
2. Select the **Type a message** box and type your message.
3. Press **Enter**, or select the send icon.

   **Tip:** Press **Shift+Enter** to start a new line without sending.

**Note:** If the box is unavailable, the 24-hour window has closed or the number isn't set up to send. See [Understand the 24-hour messaging window](#understand-the-24-hour-messaging-window).

## To send a file, image, or voice message

**To attach a file:**

1. In the composer, select the paperclip icon, then choose a file.

   You can also drag a file onto the chat window, or copy an image and press **Ctrl+V**.

2. In the **Add a caption** box, type a caption. This is optional.
3. Select the send icon.

**To send from the media library:**

1. In the composer, select the library icon.
2. Search for the item and select it.
3. Select the send icon.

**To record a voice message:**

1. In the composer, select the microphone icon. Recording starts and a timer appears.
2. Speak your message.
3. Select the stop icon to finish, or **Cancel** to discard it.
4. Select the send icon.

**Note:** On Instagram, file attachments, the media library, and voice messages aren't available yet. The buttons are unavailable and explain why when you point at them.

## To send a template

Send an approved template when the 24-hour window has closed, or when you're messaging someone for the first time.

1. In the composer, select the plus icon. A menu appears.
2. Select **Send a template**. The **Send Template** dialog appears.

   ![Figure 14. Send a template](/img/Assets/Figure%2014%20-%20Send%20a%20template.png)
   ***Figure 14.** Send a template*

3. In the **Search templates** box, find the template you want. Only templates approved for this number appear.
4. Select the template. A preview appears.
5. Fill in a value for each variable the template uses.
6. Select **Send**.

**Note:** Sending a template to someone who hasn't messaged recently reopens the 24-hour window as soon as they reply.

## To send a form

1. In the composer, select the plus icon.
2. Select **Send a form**.
3. In the **Search forms** box, find the form you want.
4. Select the form, then select **Send**. The contact receives a link that opens their own copy of the form.

Responses appear on the form's **Responses** tab. See [To review responses](./Forms.md#to-review-responses).

## Understand the 24-hour messaging window

WhatsApp and Instagram both limit when you can send a free-form message.

| Channel | Rule | What Zprox.Chat does when it closes |
|---|---|---|
| **WhatsApp** | You can send free text only within 24 hours of the customer's last message. | The composer is disabled and reads *Reply window closed — send a template instead.* Use **Send a template**. |
| **Instagram** | The standard window is 24 hours. A human-agent reply extends your reach to 7 days. | The composer is disabled and a notice appears above it. Use the human-agent reply box, or wait for the customer to message again. |

**Note:** To avoid the window closing on an active lead, set up the 24-hour window reminder ([To set up the 24-hour window reminder](./Getting%20Started.md#to-set-up-the-24-hour-window-reminder)) and turn on **Auto-remind** for that conversation.

For the full policy, see [https://faq.whatsapp.com/](https://faq.whatsapp.com/).

## To reply to a specific message

1. Point at the message you want to answer.
2. Select the reply icon. The message appears as a quoted block above the composer.
3. Type your reply and send it.

**To cancel:** Select the close icon on the quoted block.

## To tag a contact from the chat

1. In the chat header, select the tag icon. The **Groups** menu appears, organised by category.
2. Select a group to apply it. Select it again to remove it.
3. Select anywhere outside the menu to close it.

**Note:** A contact can hold only one group per category. Selecting a second group in the same category replaces the first.

## To assign a conversation to a team member

**Admin only.**

1. In the chat header, select the assign icon.
2. Select the person who should own the conversation, or select **Unassigned** to clear the owner.

The assigned person sees the conversation in their inbox. Sales users only see conversations assigned to them.

## To take over from an AI agent

When an AI agent is answering a conversation, a robot icon appears in the chat header with a green dot.

1. Select the robot icon. The agent pauses and the dot turns amber. You now answer the conversation yourself.
2. Select the icon again to hand the conversation back to the agent.

## To search messages

1. In the chat header, select the search icon.
2. In the **Search messages** box, type what you're looking for. Matching messages are highlighted in the timeline.
3. Select the close icon to leave search.

## To export a chat

1. In the chat header, select the more-options icon.
2. Select **Export chat**. Zprox.Chat downloads the conversation as a file.

**Note:** **Export chat** is unavailable when the conversation has no messages.

## To use the contact details panel

The panel on the right shows who you're talking to and what you know about them.

| Card | What it shows |
|---|---|
| **Contact information** | Name, channel, masked phone number, and email address. |
| **Lead & ownership** | Lifecycle stage, lead score, and the assigned team member. |
| **Groups & labels** | Every group applied to the contact. |
| **Opt-out notice** | Appears when the contact asked to stop automated messages. |

**To edit the contact:** In the chat header, select the pencil icon next to the name, or select **More options** > **Contact info**.

**Important:** If the panel shows that a contact opted out, don't message them with marketing content.
